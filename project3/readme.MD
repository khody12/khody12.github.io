Correspondences for the necessary images are commented out on top of main.py, depending on which one you want to use, you will need to uncomment the right correspondences, and then change which images you need to load in near the bottom



For the final part when you are stiching the images together. Please make sure to uncomment out the corners lists. Those were created during the interpolation processes, if you don't use them and use the output of the functions,
you may run into an error where it doesn't see the values as an integer.
